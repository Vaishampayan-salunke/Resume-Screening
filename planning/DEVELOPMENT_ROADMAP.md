# TalentLens Phase 2 — Development Roadmap (12-Week Academic Plan)

## Weeks 1–2: Requirements, Setup & Architecture
- Workspace inspection and consolidation.
- System architecture definition and database schema finalization.
- Research dataset cataloging (Kaggle Updated Resume, SkillSpan, ESCO).
- Project documentation generation.

## Weeks 3–4: Authentication, Profile & Dashboard
- User registration, login, JWT token auth, and profile onboarding.
- Unified Career Profile with Profile Evidence (skills tied to projects/experience).
- Personalized command center dashboard with readiness index and next best actions.

## Weeks 5–6: Multi-Format Parsing & Hybrid Matching
- PDF & DOCX parser with python-docx and PyMuPDF.
- PII anonymization pipeline.
- SBERT embeddings + TF-IDF lexical baseline.
- 6-factor hybrid compatibility model and explainability engine.

## Weeks 7–8: Career Discovery & Learning Roadmaps
- Multi-role career path recommendation engine.
- Interactive *Career Path Simulator* ("What if I learn SQL and Docker?").
- Phase-by-phase personalized learning roadmaps with curated verified resources.

## Weeks 9–10: Opportunity Discovery & Application Tracking
- Company & job listings browser with India and international filters.
- Adzuna provider integration with structured offline fallback.
- "Why am I recommended for this job?" explainability report.
- Kanban & list view Application Tracker.

## Weeks 11–12: AI Interview Studio, Fairness & Academic Defense
- Role-specific mock interview workspace with text answer evaluation and STAR feedback.
- Counterfactual demographic perturbation fairness auditing.
- Automated test suites (pytest + vitest/build).
- Final project documentation and demonstration readiness.
